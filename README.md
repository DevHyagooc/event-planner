# 📅 Event Planner

O EventPlanner é um aplicativo mobile desenvolvido para facilitar a organização e o planejamento de eventos pessoais e profissionais. A plataforma permite criar eventos, gerenciar tarefas, acompanhar prazos e organizar responsabilidades em um único ambiente, reduzindo esquecimentos e melhorando o controle do planejamento.

O projeto foi pensado para oferecer uma experiência simples, prática e intuitiva, auxiliando usuários desde pequenas confraternizações até eventos de maior complexidade.

---

## 🚀 Funcionalidades

- Autenticação
- Gerenciamento de Eventos
- Agenda
- Tarefas
- Perfil do Usuário

# 📲 Como executar

1. Clone o repositório: `git clone https://github.com/`

2. Instale as dependências: `flutter pub get`

3. Execute o aplicativo (roda em localhost): `flutter run -d web-server`
